Curso de HTML

Aprenda a criar páginas para a web

O curso de HTML apresenta os fundamentos usados para estruturar páginas da internet. Durante a formação, o estudante aprende a organizar textos, imagens, links, tabelas e formulários com uma marcação clara e semântica.

Entre os principais conteúdos estão a estrutura básica de um documento HTML, títulos e parágrafos, listas, links, imagens, tabelas, formulários e elementos semânticos. O curso também mostra como criar páginas acessíveis e preparadas para receber estilos CSS.

O que você poderá desenvolver

Habilidade
Estruturar páginas usando elementos HTML
Criar formulários com campos, rótulos e validações
Organizar conteúdo com tags semânticas
Preparar páginas para integração com CSS e JavaScript
