Missão da equipe de QA

Este sistema faz parte de uma atividade de testes de software. Não presuma que tudo está correto.

  • Analise os requisitos fornecidos pelo professor.
  • Crie cenários e casos de teste.
  • Teste dados válidos e inválidos.
  • Registre os resultados como PASSOU, FALHOU ou BLOQUEADO.
  • Documente cada defeito encontrado com passos para reprodução.
