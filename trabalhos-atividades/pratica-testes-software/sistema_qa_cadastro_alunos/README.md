# Sistema QA — Cadastro de Alunos

Projeto educacional para aulas de Testes de Software / QA.

## Como executar

Não é necessário servidor.

1. Extraia o ZIP.
2. Abra `index.html` em um navegador.
3. Utilize `documentacao/requisitos.md` para elaborar os testes.

## Estrutura

- `index.html` — aplicação web
- `css/style.css` — estilos
- `js/app.js` — lógica JavaScript
- `documentacao/requisitos.md` — requisitos para os alunos
- `documentacao/atividade_alunos.md` — roteiro da atividade
- `documentacao/gabarito_professor.md` — bugs intencionais (uso exclusivo do professor)

## Sugestão didática

Faça os alunos receberem o sistema e os requisitos, mas NÃO entregue o gabarito.

Eles devem descobrir os problemas por meio de testes.
