Antes de começar

Perguntas frequentes

Preciso saber programar?

Não. O curso começa pela base e conduz você passo a passo pela construção de uma página HTML5.

Vou aprender apenas HTML?

O foco é HTML5, mas você também entenderá como a marcação se conecta ao CSS e prepara o terreno para o JavaScript.

O projeto final pode entrar no meu portfólio?

Sim. Ao final, você terá uma página estruturada para continuar estilizando e apresentar como parte dos seus primeiros trabalhos.

Como faço minha inscrição?

Acesse a página de registro pelo botão de inscrição e preencha seus dados para iniciar o processo.
