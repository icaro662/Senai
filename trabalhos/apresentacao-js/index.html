01 — O que é JavaScript?

A linguagem que dá vida à página.

JavaScript é uma linguagem de programação muito utilizada no desenvolvimento web. No Front-End, ela permite criar comportamentos, responder às ações do usuário e atualizar a página sem precisar recarregá-la.

HTML

Define títulos, textos, imagens, formulários e outros elementos.

CSS

Define cores, tamanhos, espaçamentos e layout.

JavaScript

Cria lógica, eventos, validações e interações.

04 — DOM

O DOM é a ponte entre HTML e JavaScript.

DOM significa Document Object Model. É a representação da página HTML que permite ao JavaScript acessar e modificar seus elementos.

HTML DOM JavaScript

O usuário interage → o evento acontece → JavaScript modifica o DOM → a interface muda.

<h1 id="titulo">Olá!</h1>

document.getElementById("titulo").innerHTML = "Novo título";

Olá!

05 — Demonstração prática

Uma pequena página pode demonstrar tudo isso.

Interação + DOM + eventos + validação + feedback.

Demonstração ao vivo

Cadastro rápido

Preencha o formulário e veja o JavaScript trabalhando.

Código da demonstração

HTML + JavaScript

<form id="formDemo">
<input id="formNome">
<input id="formEmail">
<input type="password" id="formSenha">
<input type="password" id="formConfirmacao">
<button type="submit">Enviar</button>
</form>
document.getElementById("formDemo").addEventListener("submit", function (event) {
  event.preventDefault();

  const nome = document.getElementById("formNome");
  const email = document.getElementById("formEmail");
  const senha = document.getElementById("formSenha");
  const confirmacao = document.getElementById("formConfirmacao");
  const feedback = document.getElementById("formFeedback");

  const mostrarErro = (mensagem) => {
    feedback.innerHTML = mensagem;
  };

  if (nome.value.trim().length < 3) {
    mostrarErro("Digite um nome com pelo menos 3 caracteres.");
    nome.focus();
    return;
  }

  if (!email.validity.valid) {
    mostrarErro("Digite um e-mail válido.");
    return;
  }

  const senhaForte = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$/;

  if (!senhaForte.test(senha.value)) {
    mostrarErro("A senha deve ter 8 caracteres, letra maiúscula, minúscula e número.");
    senha.focus();
    return;
  }

  if (senha.value !== confirmacao.value) {
    mostrarErro("A confirmação de senha não coincide.");
    confirmacao.focus();
    return;
  }

  feedback.innerHTML = "Cadastro realizado com sucesso!";
});
