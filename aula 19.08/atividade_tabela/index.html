Qual a diferença entre th e td?

A tag th cria um header na tabela, enquanto td cria uma célula.


Por que devemos utilizar thead, tbody e tfoot?

Utilizamos para organizar semanticamente o contéudo do código.


Qual a finalidade do atributo scope="col"?

Este atributo tem finalidade de representar a ferramentas de acessibilidade que tal elemento th é uma coluna.


Em que situações seria utilizado scope="row"?

Para especificar que tal elemento th representa uma linha.
